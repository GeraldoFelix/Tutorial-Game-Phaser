## 📝 Sobre o Projeto
O objetivo deste tutorial foi aprender os pilares básicos de uma engine de jogos:
* **Carregamento de Assets:** Importação de imagens e spritesheets.
* **Física (Arcade Physics):** Gravidade, colisões e plataformas sólidas.
* **Entrada de Usuário:** Controle do personagem via teclado.
* **Lógica de Pontuação:** Coleta de itens (estrelas) e atualização do placar.
* **Game Over:** Condições de derrota ao tocar em obstáculos (bombas).

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** JavaScript
* **Engine:** Phaser 3
* **Hospedagem:** GitHub Pages

## 🕹️ Como jogar?
1.  Use as **setas do teclado** para se movimentar.
2.  Pule nas plataformas para coletar as **estrelas**.
3.  Evite as **bombas** a todo custo! Se tocar em uma, o jogo termina.
